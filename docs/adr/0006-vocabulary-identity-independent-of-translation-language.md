# Keep Vocabulary Item identity independent of translation language

A reader learns the same source-language vocabulary even when capturing translations into different target languages, so Vocabulary Item identity is normalized lemma plus source language, with shared Encounter history and learning state. Retain target-language translations under that Vocabulary Item instead of creating independent learning items for each translation language, using the latest explicitly saved nonempty translation per target language while preserving translation snapshots on new Encounters. This requires consolidating existing duplicate items and their references while preserving available history rather than merely changing the deduplication function; agreed migration and capture behavior are recorded in `.scratch/vocabulary-item-identity/spec.md`.
