# Keep Windows presentation independent while sharing product workflows

The Windows 11 application will use its own Svelte main-window and capture-window presentation instead of extending the unfinished macOS page components. Windows and macOS continue to share domain and application behavior, frontend-facing data contracts, capture state rules, and platform capability contracts; they do not share page-level components or platform-specific styling by default. This prevents unresolved macOS UI behavior from defining or blocking Windows work without duplicating the product core or introducing a second native UI technology stack.
