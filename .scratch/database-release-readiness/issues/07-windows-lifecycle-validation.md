# 07: 完成 Windows 安装生命周期演练

**What to build:** 在隔离 Windows 环境中证明安装、升级、重装与卸载的数据行为符合用户约定。

**Blocked by:** 06：实现主动卸载清理、升级保留数据

**Status:** ready-for-agent

- [ ] 使用隔离 Windows 用户或虚拟机、合成词汇数据和独立开发目录，不操作真实用户数据库。
- [ ] 记录 OS、安装包版本、提交、SHA256、前置状态、操作步骤和实际结果，保存可复核证据。
- [ ] 验证新装、旧版升级、同版本重装、主动卸载、卸载后重装；升级与重装保留词汇和设置，卸载后重装不恢复旧私人词库。
- [ ] 验证正式版数据全部按白名单清理，外部 CSV、手动文件、独立开发目录及共享运行时保留。
- [ ] 演练应用运行/文件占用导致的清理失败，核对残留报告；验证适用的静默安装/卸载行为。
- [ ] 不要求构建完整安装器自动化；若没有可用隔离环境，明确标记未完成，不使用编译成功替代演练证据。
- [ ] 发现错误后修复并重跑受影响场景；记录与延期备份功能相关的尚未覆盖项。
