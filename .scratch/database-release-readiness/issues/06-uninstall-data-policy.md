# 06: 实现主动卸载清理、升级保留数据

**What to build:** Windows NSIS 主动卸载明确删除正式版管理的数据，更新安装仍保留词库与设置。

**Blocked by:** 外部 P0 前置条件：正式版与开发版数据目录隔离已落实并验证；尚无对应编号，不能视为已完成。

**Status:** implemented-pending-acceptance

- [ ] 开始前验证正式/开发目录隔离；未满足时报告外部阻塞，不在共享数据目录上执行清理，不把本票扩展为全部 P0。
- [ ] 核对实际 Tauri/NSIS 模板的更新、修复、主动卸载和静默路径，使用经验证的标志区分；不能猜测升级变量。
- [ ] 用明确的当前用户正式版目录白名单覆盖数据库及附属文件、设置、WebView 数据、缓存和日志；在隔离夹具上核对解析后的绝对路径。
- [ ] 主动卸载界面说明删除范围；先结束应用并释放句柄，再执行清理，检测失败并报告残留或重试方式。
- [ ] 更新和同版本修复/重装保留数据；用户另存的 CSV、手动文件、开发目录和共享运行时不删除，不扫描磁盘寻找副本。
- [ ] 应用管理备份未来遵循同一所有权规则，但本票不实现备份，也不删除尚未明确归属的外部文件。
- [ ] 添加适当的分支/路径验证及可构建 NSIS 包；实机生命周期演练由 07 完成，本票不以静态检查宣称实机验证完成。
